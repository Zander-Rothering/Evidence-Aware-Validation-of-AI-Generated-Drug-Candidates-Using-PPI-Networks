# Archived artifacts from CHEMBL1781 era

These files were generated before discovering that CHEMBL1781 is
DNA topoisomerase 1, not HMGCR. The correct HMGCR target is
CHEMBL402.

All figures and CSVs in this folder show topoisomerase inhibitor
chemistry (camptothecin/topotecan analogs), despite titles
referencing HMGCR or statins. They are preserved for the project
report as a "before/after" methodology example, not for scientific
use.

See filter_chembl_statins.py and the CHEMBL402-based pipeline in
the parent directory for the corrected workflow.
